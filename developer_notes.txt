# TO INSTALL
https://docs.xlwings.org/en/stable/addin.html

# steps

# install addin
# bear in mind that The add-in is password protected with the password 'xlwings'
xlwings addin install

# to use RunPython or UDFs in a workbook, you need to set a reference to xlwings in the VBA editor
Tools > References...

# if you want to create a project that already has everython ser use:
xlwings quickstart

# in the case where no addin wants to be installed
xlwings quickstart myproject --standalone

https://docs.xlwings.org/en/stable/udfs.html

# FEATURES
rich-common table opperation functions
utility functions
useful examples per UDF
extendable
core function helpers to use in extensions
supports selection of entire columns in formulas (fitting actual table contents) e.g. A:A
intelillent chaching per formula block which reduces processing times recursively
Automatic test generation
Unittest helpers
tests per UDF
integrated debugger
